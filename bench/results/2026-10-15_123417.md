# Benchmark — 2026-10-15 12:34

Local test server, 3 run(s) per cell, medians of successful runs. *Tail* = time spent on the last 10 % of bytes. *Overhead* = bytes sent beyond file size.

**Machine:** WD Green SN350 1 TB NVMe (DRAM-less, 84 % full; ~87 MB/s sustained buffered writes measured with `dd`), Windows 11. dm: laggard eviction also covers the last crawler, steal threshold 400 ms.

**Caveat (clean):** all clients write into the OS cache and nobody flushes (ADR 0002), so 1 GiB in < 1 s is cache speed, not disk speed. Results on this disk vary a lot with pending write-back; an earlier run right after a 2 GB `dd` gave dm 13.2 s and aria2 24.7 s.
