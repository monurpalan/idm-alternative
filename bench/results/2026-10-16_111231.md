# Benchmark — 2026-10-16 11:12

3 run(s) per cell in shuffled client order, medians of successful runs. *Tail* = time spent on the last 10 % of bytes. *After* = from the server having sent the whole file to the client exiting (assembling parts, flushing, shutting down). *Overhead* = bytes sent beyond file size. These come from the local test server; internet scenarios (with a URL) leave them empty.

**Machine:** WD Green SN350 1 TB NVMe (DRAM-less, ~87 MB/s sustained writes), Windows 11. IDM 6.43.15 with default settings (8 connections). `dm x8` = dm limited to IDM's connection count. The *clean* times depend on pending disk write-back: an earlier run the same morning gave dm 0.82 s and curl 1.65 s.
